# Changelog

## [1.0.0]

- Release the Dart Pub CLI with `MetaEngine.Dart.OpenApi.Dio` 1.0.0.
- Generate typed Dart/Dio clients and models from OpenAPI JSON or YAML files and HTTP(S) URLs.
- Configure Dio timeouts and OAuth2 refresh with client credentials or authorization code.
- Generate native HTTP QUERY requests with typed bodies from OpenAPI 3.2 query operations.
